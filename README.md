## 更新资料

在 GitHub 仓库选择 **Add file → Upload files**，上传同名 HTML 覆盖旧文件，然后选择 **Commit changes** 提交到 `main`。GitHub Pages 会自动重新发布；发布完成后刷新站点即可。文件名保持不变，朋友使用的链接也保持不变。

如在本机编辑，建议以本文件夹中的版本为基础，以保留对移动端样式 `reading.css` 和本地 KaTeX 文件的引用。

## 发布配置

Settings → Pages → Deploy from a branch → `main` → `/ (root)`。

数学公式库为 KaTeX 0.16.9，许可证见 `KATEX-LICENSE.txt`。字体已内嵌于公式样式表，阅读时无须连接外部 CDN。
